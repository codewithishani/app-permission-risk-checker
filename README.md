# 🔐 App Permission Risk Checker

## 📌 Project Description

The **App Permission Risk Checker** is a web-based Information Security and Cyber Laws (ISCL) micro-project developed using **HTML, CSS, and JavaScript**.

The system helps users understand the potential privacy and security risks associated with application permissions. Users can enter an application name, select its category, and choose the permissions requested by the application. The system then analyzes the selected permissions using a predefined risk-scoring model and displays a **Risk Score, Risk Level, Selected Permissions, and Security Recommendations**.

This project is designed as an **educational risk assessment tool** to improve awareness about application permissions and privacy.

## 🎯 Objectives

- To create awareness about application permissions.
- To identify permissions that may involve higher privacy risks.
- To calculate a basic permission-based risk score.
- To classify applications into Low, Medium, or High Risk.
- To provide simple security recommendations to users.
- To demonstrate basic Information Security concepts through a web application.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Web Browser

## 🔐 Permissions Analyzed

The system analyzes the following permissions:

- 📷 Camera
- 🎤 Microphone
- 📍 Location
- 👥 Contacts
- 💬 SMS
- 📞 Phone
- 📁 Files / Storage

## 📊 Risk Assessment

Each permission is assigned a predefined risk value. The total risk is calculated and converted into a score out of 10.

### Risk Levels

- 🟢 **0–3: Low Risk**
- 🟠 **4–6: Medium Risk**
- 🔴 **7–10: High Risk**

## ⚙️ Main Features

- Application name and category input
- Reference application profiles
- Automatic permission selection for sample applications
- Manual permission selection
- Permission count
- Permission-based risk scoring
- Risk level classification
- Security recommendations
- Result page
- Reset and Analyze Another App options
- Responsive user interface
- Educational security disclaimer

## 🔄 Working of the System

1. The user opens the App Permission Risk Checker.
2. The user enters the application name and category.
3. The user selects the required permissions or chooses a reference application.
4. The system counts the selected permissions.
5. Each selected permission is assigned a predefined risk value.
6. The system calculates the overall risk score.
7. The application is classified as Low, Medium, or High Risk.
8. The result page displays the score, risk level, selected permissions, and security recommendations.

## ⚠️ Limitations

This project provides a **basic educational risk assessment** based on selected application permissions.

It does not directly scan installed applications or verify whether an application is actually safe or malicious. The reference application profiles are sample profiles stored in the JavaScript code, and actual permissions may vary depending on the application version, device, operating system, and enabled features.

## 🔒 Security Awareness

Users should review application permissions carefully and provide only the permissions that are necessary for an application's intended functionality.
